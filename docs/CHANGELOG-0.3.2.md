# NppXsdViewer 0.3.2

## Diagram kapszulák

- Az `S`, `C`, `A` rövidítések helyett a kompozitor teljes neve jelenik meg: `sequence`, `choice`, `all`.
- A kompozitor jelölő körök helyett dinamikus szélességű, lekerekített kapszulák vannak.
- A kapszula szélessége a felirat tényleges méretéhez igazodik.
- A `+` / `-` kapcsoló a kapszula jobb szélén, függőlegesen középre igazítva jelenik meg.
- Az öröklési kapcsolat egységes `extends` kapszulát kapott.
- A diagram vízszintes rést megnöveltük, hogy a dinamikus kapszulák ne ütközzenek a következő szint csomópontjaival.
