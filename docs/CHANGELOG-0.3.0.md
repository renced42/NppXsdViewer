# NppXsdViewer 0.3.0

- Jobb oldali tabos tulajdonságpanel: általános adatok, pattern, enumerációk, facetek, attribútumok, dokumentáció.
- Diagramdobozok egyszerűsítése: csak név és típus.
- Alapból becsukott gyökérelem és kézi lazy kibontás.
- Mélységkorlát és Illesztés funkció eltávolítása.
- Mind kinyit / Mind becsuk működés.
- PMT25 Chain elemek korlát nélküli, ciklusvédett kibontása.
- Zoom és szövegréteg javítása: DrawString és közös GDI+ transzformáció.
