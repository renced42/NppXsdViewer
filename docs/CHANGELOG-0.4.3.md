# NppXsdViewer 0.4.3

## Property panel layout

- Replaced the right-side tab control with vertically stacked property sections.
- Each section is displayed in its own bordered box.
- Empty sections are hidden automatically.
- Long lists keep their own native scrollbar inside the section.
- The complete right-side property area is also vertically scrollable when all visible sections do not fit.
- Section headers can be clicked to collapse or expand the individual box.
- Existing sections remain available: General, Pattern, Enumerations, Restrictions, Attributes, Documentation, Used by, Dependencies and Problems.
