# NppXsdViewer 0.3.4

## English-only user interface

- All user-facing plugin labels are now in English.
- Notepad++ plugin menu commands are now `Show XSD diagram` and `Refresh XSD diagram`.
- Toolbar actions are `Back to list`, `Collapse all`, `Expand all`, and `Refresh`.
- Schema list headers are `Element`, `Type`, and `Documentation`.
- The root selector label is `Root element:`.
- Property tabs are `General`, `Pattern`, `Enumerations`, `Restrictions`, `Attributes`, and `Documentation`.
- Property grid and attribute grid headers are fully English.
- Status messages, plugin error dialogs, resolver errors and XSD loading errors are also English.
- XSD documentation text itself is never translated; the viewer shows the documentation contained in the schema unchanged.
